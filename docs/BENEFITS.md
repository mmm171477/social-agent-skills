# What the Social Agent Skills suite does for you

## The problems it targets
1. **Every post starts from zero.** Each platform skill gives your AI agent a repeatable way of working for that platform (packaging for YouTube, carousels and Reels for Instagram, hooks and experiments for TikTok, access checks for Snapchat, consent for WhatsApp), instead of generic "write me a caption" answers.
2. **One idea pasted everywhere.** `social-media-core` adapts one source idea into native versions per platform and keeps brand, calendar and quality checks consistent.
3. **Agents that publish or message without a human.** Every skill shows the exact action and waits for approval before any external write, and refuses fake engagement, scraping and unsolicited bulk messages.
4. **Claims nobody checked.** Each skill ends with checklists: facts, rights, disclosures, accessibility, and "unknown" instead of invented numbers.

## What you hold after using it
| After you do this | You have |
|---|---|
| Ask `youtube-agent` to package a video | title/thumbnail pairs, chapters, a description and a pre-flight list |
| Ask `instagram-agent` for a carousel | slide-by-slide script with alt text, caption variants and an approval summary |
| Ask `tiktok-agent` for hooks | five distinct hooks, a beat sheet, a shot list and an experiment log |
| Ask `snapchat-agent` about access | an access path (tool, manual or requires_setup) before any content |
| Ask `whatsapp-agent` for templates | consent-checked templates, a pre-flight list and an escalation rule |
| Ask `social-media-core` for a campaign | a brief with gaps listed, a calendar with owners and approvers, platform hand-offs |
| *(Pro, separate download)* Use the commercial kit | campaign playbooks, a QA scorecard, a content calendar, client onboarding and brand-voice templates, with filled examples |

## Who benefits most
Creators, small brands and agencies who already use an AI agent (Claude Code or similar skills-capable tools) for social content and want consistent, checked work rather than one-off prompts.

## How to know whether it is worth it for you
Do `TRY-IT.md` (about 20 minutes, free): install one skill, run its sample prompts on your own brand, and tick the checklists with `scripts/print_activation_cases.py`. **Judge by:** does the agent follow the workflow, stop at the approval gate, and refuse the boundary prompts? This suite makes no claim about reach, followers, leads or revenue.

## What it does not do
No connectors, accounts, API keys or automatic posting. Platform rules change: each skill tells the agent to check the official source before relying on a limit or feature.
