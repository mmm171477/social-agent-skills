# Worked example — one product, five hooks, one test (illustrative, fictional brand)

**Brand:** "Harbor Coffee Lab". **Product:** a hand grinder. **Goal:** first-time buyers.

1. **One viewer problem.** "My coffee tastes sour and I do not know why."
2. **Five hooks, five different angles** (write all before choosing):
   - Mistake: "You are grinding this wrong."
   - Result: "Same beans, same water, different cup. Taste the difference."
   - Question: "Why does cheap coffee taste better here?"
   - Challenge: "Try this for one week."
   - Story: "I wasted a bag of beans before I learned this."
3. **Beat sheet for the winner (20 seconds).** Hook line on screen → show the problem → one change → show the result → one line call to action.
4. **Shot list.** Three shots, one location, natural light, vertical, captions on screen.
5. **Caption and sound.** Short caption; audio only if usage rights cover the account type. Flag any claim that needs a source.
6. **Capability check** (`references/tiktok-capability-check.md`): does the connected app direct-post, or only create a draft? If unknown, mark `requires_setup` and give a manual upload checklist.
7. **Approval gate.** Show account, video file, caption, settings, schedule and time zone. Wait for approval.
8. **Experiment.** Test hook A vs hook B with the rest identical; log hypothesis, change, date, window and result (`references/experiment-log-template.md`). Decide: keep, kill or iterate.

Output delivered: five hooks, one beat sheet, shot list, caption, capability result, experiment log entry.
