# Instagram capability verification

Never assume all Instagram features are available through one API login path. Validate separately: professional account eligibility, linked Page/business assets, account type, publishing format, Stories, Reels, carousel support, comments, mentions, messaging and insights. Record API version, scope names, app review state, account identifier and verification date.

Official starting points:
- Instagram Platform: https://developers.facebook.com/docs/instagram-platform/
- Content Publishing: https://developers.facebook.com/docs/instagram-platform/content-publishing/
- Meta for Developers: https://developers.facebook.com/docs/

Do not publish from personal/consumer accounts through unsupported scraping or browser automation.
