# Instagram publishing checklist

- [ ] Correct professional account and authorized login path
- [ ] Requested format is supported for this account and API version
- [ ] Asset dimensions, duration, encoding and public accessibility validated
- [ ] Cover, caption, tags, mentions and destination verified
- [ ] Audio, image, font and creator rights confirmed
- [ ] Disclosure, accessibility and brand review complete
- [ ] Exact post and schedule previewed
- [ ] Approval reference recorded
- [ ] Provider publication state and media ID verified
