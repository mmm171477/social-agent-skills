# Changelog

## 0.2.0 — 2026-11-08
- First standalone release of `whatsapp-agent`: installable on its own, with an approval gate before every external action.
- Consent-first messaging workflow with a consent register template, pre-flight check and escalation policy.
- Added `references/playbook.md` and a worked order-status example.
- Activation tests for WhatsApp-specific and out-of-scope requests (spam, unofficial clients).
