# Worked example — one announcement, three platforms (illustrative, fictional brand)

**Brand:** "Harbor Coffee Lab". **Source:** an announcement, "Our new hand grinder ships in two weeks".

1. **Brief.** Complete the brand brief (`references/brand-brief-template.md`): audience (home brewers), voice (friendly, practical), pillars (learn, gear, community), claims we can prove, claims we must not make. Gaps are listed, not guessed.
2. **One idea, three native forms.**
   - YouTube: a "why we built it" video, with a packaging pair. → hand to `youtube-agent`.
   - Instagram: a 6-slide carousel on what changed in the design. → hand to `instagram-agent`.
   - TikTok: five hook options for a 20-second demo. → hand to `tiktok-agent`.
3. **Calendar.** Four weeks: tease, reveal, proof, offer. One owner and one approver per item (`content-calendar.csv` in the Pro kit).
4. **QA gate** (`references/content-qa.md`): facts and numbers sourced, no unverifiable claims, rights cleared, disclosures present, text readable, alt text where relevant.
5. **Approval summary.** One page per week: each item, platform, date, asset, caption, owner. A human approves.
6. **Review loop.** Weekly: pick one metric per platform that matches that item's goal, note the window, write one decision ("keep, change, stop") per item.

Output delivered: completed brief with gaps, 4-week calendar, three platform hand-offs, QA results, weekly approval summaries, review log.
