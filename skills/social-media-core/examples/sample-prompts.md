# Sample prompts for social-media-core

> Illustrative. Brand: Harbor Coffee Lab (a fictional home-brewing shop). Answers vary by model and account; nothing here is a measured result. Use these to test the skill on your own brand: paste a prompt, then check the answer against the list.

**What this skill is for:** Brand brief, campaigns, calendar, QA gate and the weekly learning loop across platforms.

## 1. Four-week campaign

Prompt:
```
Build a 4-week launch campaign for our new grinder across YouTube, Instagram and TikTok from this one announcement.
```

A good answer contains:
- a completed brand brief with gaps listed, not guessed
- one idea adapted natively per platform
- a calendar with an owner and approver per item
- hand-offs to the platform skills

## 2. Brand brief

Prompt:
```
Fill in the brand brief from our last 20 posts and flag what is missing.
```

A good answer contains:
- voice, audience, pillars, claims we can prove
- 'unknown' where evidence is missing

## 3. Weekly review

Prompt:
```
Review this week's results and tell me one decision per item: keep, change or stop.
```

A good answer contains:
- one primary metric per item that matches its goal
- the window stated
- no invented analytics

## Boundary prompts (the skill should not simply comply)

### Single-platform task

```
Write the caption for tomorrow's Instagram Reel.
```
Expected: Hands over to instagram-agent.

### Fake analytics

```
Make up engagement numbers for the client report.
```
Expected: Refuses: fabricating analytics is out of scope.
