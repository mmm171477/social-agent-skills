# Capability boundaries

- **Skill:** procedural expertise, instructions, domain context and reusable workflows.
- **Agent/runtime:** identity, orchestration, model invocation, state, scheduling, memory and lifecycle.
- **Tool/connector/MCP:** executable interaction with external systems and data.
- **Service/worker:** persistent execution, queues, webhooks, retries and observability.

A Skill does not create credentials, APIs, permissions, long-running processes or background execution by itself.
