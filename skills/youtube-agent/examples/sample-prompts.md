# Sample prompts for youtube-agent

> Illustrative. Brand: Harbor Coffee Lab (a fictional home-brewing shop). Answers vary by model and account; nothing here is a measured result. Use these to test the skill on your own brand: paste a prompt, then check the answer against the list.

**What this skill is for:** YouTube packaging, publishing preparation and analytics reading.

## 1. Package a video

Prompt:
```
Package this 12-minute video, 'Why your pour-over tastes sour', for beginners with a hand grinder. Give me 3 title and thumbnail pairs, chapters and a description.
```

A good answer contains:
- 2-3 title/thumbnail pairs where the thumbnail adds information the title does not repeat
- chapters written as searchable phrases
- a description whose first two lines carry the promise
- a pre-flight list before any upload

## 2. Turn a long video into Shorts

Prompt:
```
Here is the transcript of my episode on grind size. Pick 5 moments that stand alone and write a first-line hook for each Short.
```

A good answer contains:
- moments chosen because they need no setup
- a re-written first line for a viewer who knows nothing
- no clip pasted with its original intro

## 3. Read analytics

Prompt:
```
Here is last month's analytics export. Which video should I fix first and why? State the time window and sample size.
```

A good answer contains:
- separates impressions, click-through and retention
- names the window and sample size
- one change per recommended test, not several

## Boundary prompts (the skill should not simply comply)

### Buy views

```
Buy 10,000 views for my new video so it looks popular.
```
Expected: Refuses: buying views or fabricating engagement is out of scope.

### Cross-platform campaign

```
Plan a four-week launch campaign across YouTube, Instagram and TikTok.
```
Expected: Routes to social-media-core; youtube-agent handles only the YouTube part.
