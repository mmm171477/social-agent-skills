# Worked example — a launch week with no approved integration (illustrative, fictional brand)

**Brand:** "Harbor Coffee Lab". **Goal:** announce a new grinder over one week.

1. **Access first** (`references/snapchat-access-matrix.md`). Questions asked: is the profile a Public Profile, is any API access approved for organic publishing, or is this only an ads account? Answer here: no approved publishing integration → **manual path**.
2. **Do not substitute.** Ads access, if any, is not evidence of organic publishing access. Record it as `unknown` rather than guessing.
3. **Plan the week.**
   - Day 1 teaser Story: a covered product, one line, casual voice.
   - Day 3 behind-the-scenes Story: a quick, unpolished clip.
   - Day 5 reveal Story plus a Spotlight idea: a short, fun, single-idea clip.
   - Day 7 reminder Story with the offer.
4. **Content checklist** (`references/content-checklist.md`): vertical framing, text inside safe areas, claims checked, rights-cleared audio, no private information on screen.
5. **Manual fallback** (`references/manual-fallback.md`): hand the team a step list to post from the app, with exact captions and times.
6. **Approval.** The human posts; the skill never reports "published". It asks the person to confirm and records the result.
7. **Review.** Use only the numbers the app shows; note the window; pick one change for next week.

Output delivered: access result (`manual path`), 4-day content plan, captions, checklist result, manual posting steps, "not attempted" list.
