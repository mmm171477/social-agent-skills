# Snapchat playbook

## 1. Start with access, not content
Decide the path before creating anything:
| Situation | Path |
|---|---|
| Approved integration for organic Public Profile publishing, tools exposed by the host | Prepare, then post through the tool after approval |
| Public Profile exists, no approved integration | Manual path with exact captions and times |
| Only an advertising account | Not evidence of organic publishing; treat as manual path or unknown |
| Unsure | Mark `requires_setup` and list the questions to answer |

## 2. Native feel
Casual, immediate, human. Short clips, clear framing, plain captions. Overproduced ad-style creative usually feels out of place. One idea per snap or story beat.

## 3. Stories and Spotlight
- **Stories:** sequence with a clear beginning, middle and end across a few snaps.
- **Spotlight:** a single, self-contained idea that makes sense with no prior context.
Check current eligibility and requirements for each in the official docs before promising either.

## 4. Safety and brand
No personal information, no unverified claims, rights-cleared audio, and a second pair of eyes on anything with a person or location in frame.

## 5. Measurement
Use only what the app or approved tool shows; record the window; do not extrapolate from a single story. Choose one change for the next week.

## 6. Never
Assume permission, treat ads access as publishing access, scrape or use unofficial clients, or report a post as live without confirmation.
