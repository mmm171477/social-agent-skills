# Snapchat access matrix

Record these independently: Public Profile API access, Ads API access, profile eligibility, app allowlisting/approval, granted permissions, region/account constraints, media endpoints and available insights. An Ads API token does not imply organic Public Profile publishing permissions. Mark unverified capabilities `requires_setup` or `unknown`.

Official starting points:
- Public Profile API: https://developers.snap.com/api/marketing-api/Public-Profile-API/Introduction
- Snap developer portal: https://developers.snap.com/
- Marketing API: https://developers.snap.com/api/marketing-api/
